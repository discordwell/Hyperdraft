# SCP Containment TCG — Strategy Doc

Persistent strategic memory for the SCP engine in Hyperdraft (Antimemetic
Cold War, Ethics Reckoning, Mnestic Reset Division, plus the three
starter Site briefings). A fresh Claude instance piloting the format
reads this BEFORE every game and consults it during play.

The doc is paired with `src/ai/scp_adapter.py` and the per-archetype
heuristic biases. When an LLM-piloted match reveals a blind spot,
patch BOTH this doc and the adapter.

## How to update this file at end of game

Append a `## Session takeaway — <UTC date>` section at the bottom:
- **Site briefing I ran**
- **Opposing briefing**
- **Result**: win/loss + final secrecy / ethics debt / containment count
- **One mechanical lesson** — anomaly research order, when to seal vs
  open, when to spend ethics, breach risk management
- **One engine gap** if any, tagged `gap:`
