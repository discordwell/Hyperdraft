# SCP Art Direction Defaults

Use this when SCP is the target set or as an example for other Hyperdraft set packets.

## Core Fantasy

Original SCP-inspired containment TCG art: classified facilities, anomalous objects, hostile information, bureaucratic horror, covert response teams, ethical compromise, public cover stories, and strange moments captured like evidence from an impossible incident.

## Visual Pillars

- **Containment realism:** concrete corridors, blast doors, observation glass, hazard tape, fluorescent lights, analog monitors, archival boxes, sealed rooms.
- **Practical horror:** the anomaly feels physically present or operationally dangerous, even when surreal.
- **Analog bureaucracy:** clipboards, red folders, stamped dossiers, file rooms, pneumatic tubes, paper trails, whiteboards, witness forms.
- **Public crisis:** press rooms, street panic, leaked footage, emergency cordons, broadcast bunkers, motorcades.
- **Memetic weirdness:** missing faces, impossible reflections, absent shadows, repeated figures, unreadable diagrams, memory gaps suggested by composition.
- **Ethics pressure:** aftercare wards, consent rooms, tribunals, volunteer facilities, clean clinical spaces with uneasy implications.

## Palette Ranges

Use a controlled range per card, not all at once:

- clinical white, gray concrete, institutional green
- black archive shadows, redacted black bars as abstract shapes only
- sodium amber, emergency red, monitor cyan
- wet asphalt, cold moonlight, dusty paper beige
- occult silver, bruised violet, sickly fluorescent yellow

## Variety Rules

Do not let SCP become "a monster centered in a dark hallway" for every card. Rotate:

- anomaly visible, anomaly implied, aftermath, staff reaction, facility detail, public leak, procedure in progress
- sterile containment room, exterior security cordon, file archive, elevator, newsroom, sleep lab, maintenance tunnel, ethics clinic
- human-scale fear, bureaucratic absurdity, mythic impossible scale, quiet dread, urgent response

## Card-Type Defaults

- **SCP_ANOMALY:** show the anomalous subject or its unmistakable consequence. Keep one focal anomaly unless the card concept is swarm/crowd/memetic.
- **SCP_PERSONNEL:** show a role under pressure, not a passport portrait. Hands, tools, posture, and environment should reveal job function.
- **SCP_FACILITY:** make the location's function legible: intake, archive, lab, array, wing, tribunal, gatehouse, ward.
- **SCP_PROCEDURE:** show action, consequence, or operational detail: lockdown, amnestic broadcast, cross-test setup, ethics discharge, audit, containment attempt.
- **SCP_MANDATE:** show directive-level imagery: command table, sealed council room, symbolic facility action, large-scale policy consequence.

## Negative Prompt Defaults

No readable text, no logos, no watermarks, no UI overlays, no card frame, no mana symbols, no stat boxes, no official SCP logo, no exact copyrighted characters, no clean sci-fi spaceship aesthetic, no comic mascot tone, no generic fantasy wizard robe unless the card specifically calls for occult staff.
