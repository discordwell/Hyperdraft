## Zones

Site (your dashboard — tracks Secrecy, Breach, Ethics Debt, Archive count), Hand, Site Floor (assigned Personnel + contained Anomalies), Paperwork Queue (your stalled bureaucracy backlog), Discard, Banished.

## Turn structure

Briefing (start triggers, Secrecy adjustments, Cognitive Hazard ticks) · Paperwork (resolve queued protocols, draw 1) · Assignment (deploy Personnel to Contain / Research / Suppress tasks against Anomalies — two assignment slots by default) · Breach Audit (Anomalies you failed to contain raise Breach; Ethics Debt accrues if you used questionable methods).

## Win condition

File 7 Archives before your Site collapses. Lose if Breach hits 12, Ethics Debt hits 8, or Secrecy reaches 0 (the public finds out). It's a race against three simultaneous failure clocks — there's no opposing army, only the cost of the things you're containing.

## One quirk to know

**Personnel are spent, not summoned.** Assigning a doctor to suppress an Anomaly is a sacrifice — they don't always come back. The math is: which Personnel can I afford to lose against which task this turn? Mood and Protocol modifiers on the Anomaly itself shift the check's difficulty, so the same agent who tanks a "docile" containment can get eaten by an "agitated" one.
